# 我的网站展示（my-website-display）

一个基于 [leleo-home-page](https://github.com/leleo886/leleo-home-page) 视觉风格改造的**网站展厅**，
用来集中展示你自己的所有网站。玻璃拟态 + 极光背景，卡片式布局，支持分类、搜索、标签筛选。

**目标：纯静态、零后端、零运行额度消耗、打开 Cloudflare 网页就能部署、改一个文件就能增删网站。**

## 效果与设计

这是一个**个人项目展示页**：集中展示站主的网站、工具和作品（不是网址收藏夹）。

- 风格参考 [leleo.top](https://www.leleo.top/)：全屏壁纸背景（默认原项目壁纸 `assets/wallpaper/ocean-girl.png`）+ 半透明毛玻璃面板，自然克制
- 圆形头像 + 衬线斜体问候语「Hi, I'm YJH」+ 引号内打字机
- 页脚：访问统计（本页访问人次 / 访问人数，与 sunpanel 项目共用 `stats.web.yjhup.com` 后端）+ 两行版权：`萌ICP备20266614号`（点击到萌 ICP 查询）与 `Copyright © 2026 | Powered By YJH`（点击 YJH 到 `https://yjhup.com`），均新标签页打开
- 左侧：标签云、简介、社交按钮（收起后出现「标签 ›」按钮可随时恢复，无需刷新）；右侧：时钟、雷达环与统计
- 中部：分类标签 + 响应式卡片网格，卡片带头图封面与悬停动效
- **搜索框双模式**：前置自定义玻璃质感下拉选搜索引擎（默认 **Google**，另可选百度 / Bing / 搜狗 / 360，样式与搜索栏一致，不再是突兀的浏览器原生弹窗）；输入时实时筛选本站项目，**回车或点右侧按钮**用所选引擎搜索全网（新标签页）
- 卡片「前往」→ **一律新标签页打开**（`target="_blank" rel="noopener noreferrer"`）
- 项目按重要 / 常用程度从高到低排列（改 `data/sites.js` 里的顺序即可调整）；按 `/` 聚焦搜索，`Esc` 清空
- 响应式：宽屏三列，中等屏两列，手机单列（侧栏自动移到内容下方，不遮挡卡片）

## 核心特性

| 需求 | 实现方式 |
| --- | --- |
| 可部署到 Cloudflare Pages | 无任何构建步骤，纯 HTML/CSS/JS |
| 方便增删网站 | 只改 `data/sites.js` 一个文件 |
| 静态优先 | 默认不调用任何 Pages Function / D1 / KV |
| 不消耗免费额度 | 访客访问 = 拉取静态文件（Pages 静态请求不限量） |
| 新标签页跳转 | 所有网站链接均为 `target="_blank"` |
| 可设管理员 | GitHub 仓库协作者即可；或用可选 KV 后台 |
| 可用 D1 / KV | 提供进阶方案，见 [四](#四可选网页后台kv--d1) |

## 为什么是纯静态（额度说明）

Cloudflare 免费版各项额度：

| 资源 | 免费额度 | 本项目默认是否使用 |
| --- | --- | --- |
| Pages 静态文件请求 | **不限量** | ✅ 只用这个 |
| Workers / Pages 函数调用 | 100,000 次/天 | ❌ 不调用 |
| KV 读取 | 100,000 次/天 | ❌ 不读取 |
| D1 读取 | 100,000 行/天 | ❌ 不读取 |

**结论**：访客打开你的网站，只是在 CDN 上取几个静态文件，**不消耗 Workers/KV/D1 的任何免费额度**。
如需在网页里直接改内容（不通过 GitHub），可启用可选的 KV 后台，那会产生少量函数调用——两种方案按需选择。

## 一、部署到 Cloudflare Pages（网页操作）

无需命令行、无需 npm。二选一即可。

### 方式 A：连接 GitHub 仓库（推荐，改内容最方便）

1. 把本项目 push 到你自己的 GitHub 仓库（仓库名随意）。
2. 登录 [Cloudflare 仪表盘](https://dash.cloudflare.com/) → 左侧 **Workers 和 Pages** → **创建** → **Pages** → **导入现有 Git 存储库** → **开始使用**。
3. 连接 GitHub 并选择刚推上去的仓库 → **开始设置**。
4. 构建设置这样填：
   - **框架预设**：选择 `无 / None`（本项目不需要构建）
   - **构建命令**：留空
   - **构建输出目录**：填 `/`（根目录，因为 `index.html` 就在根目录）
   - **根目录**：留空
5. 点 **保存并部署**。等待几十秒，得到 `https://项目名.pages.dev` 的访问地址。

> ⚠️ 关键：构建输出目录一定要填 `/`（根目录），否则 Cloudflare 找不到 `index.html` 会显示空白或 404。

之后每次你在 GitHub 上修改并 commit，Cloudflare 会自动重新部署。

### 方式 B：直接上传文件夹（无需 GitHub）

1. 登录 Cloudflare 仪表盘 → **Workers 和 Pages** → **创建** → **Pages** → **直接上传** → **开始使用**。
2. 项目名随意，点 **上传**。
3. 把本项目的**整个文件夹**拖进去（要能看到 `index.html` 在第一层）。
4. 点 **部署站点**。

> 这种方式每次改内容都需要重新上传整个文件夹。想省事请用方式 A。

### 绑定自定义域名

进入你的 Pages 项目 → **自定义域** → **添加自定义域** → 输入你的域名 → 按提示操作：

- 域名 DNS 已托管在 Cloudflare：点「激活域」即可，自动配置。
- 域名在其他服务商：按提示添加一条 `CNAME` 记录指向 `你的项目.pages.dev`，再点激活。

## 二、管理员如何修改网站内容

**所有内容都在 `data/sites.js` 这一个文件里**，用 GitHub 网页版就能改，不需要本地环境。

打开仓库中的 `data/sites.js` → 点击右上角的铅笔图标（编辑）→ 修改 → 页面底部 **Commit changes** → 等待 Cloudflare 自动重新部署（几十秒）。

### 增加一个网站

在 `sites` 数组里复制一整段 `{ ... }` 粘贴到下方，改掉里面的内容即可。注意：
- 每个网站之间用英文逗号 `,` 分隔
- `id` 要唯一（随便取个不重复的英文名）
- `category` 必须等于某个分类的 `id`（见 `categories` 数组）

```js
{
  "id": "my-new-site",          // 唯一标识，别和别人重复
  "name": "我的新网站",          // 卡片标题
  "desc": "一句话介绍这个网站。", // 卡片描述
  "url": "https://example.com",  // 网站地址（新标签页打开）
  "icon": "🌟",                 // 左上角图标，emoji 或图片地址
  "image": "",                  // 可选：网站截图地址，留空用图标
  "category": "project",        // 分类 id：tool/blog/project/fun/other
  "tags": ["前端", "作品"],      // 标签，可用于搜索
  "badge": "NEW"                // 右上角小角标，留空 "" 不显示
},
```

### 删除一个网站

把要删除网站的那**一整段** `{ ... }` 连同它后面的逗号一起删掉，保存提交即可。

### 修改说明 / 主题 / 社交按钮

都在同一个文件里：

- `meta`：站点标题、`author` / `authorUrl`（页脚 Powered By 的名字与跳转）、`icp` / `icpUrl`（备案号文字与点击跳转）、`copyright`（版权行文字）、管理链接
- `theme`：头像、大标题、打字机句子、标签云、强调色、背景图、模糊度
- `searchEngines`：搜索框下拉里的搜索引擎（`name` 显示名、`url` 搜索地址，用 `{q}` 代表关键词）；增删引擎直接改这个数组，第一个是默认引擎
- `social`：社交按钮列表
- `categories`：分类名称与图标
- `sites` 的**顺序**即页面上的显示顺序，已按重要 / 常用程度排好，挪动整段 `{...}` 即可调整

背景默认是原项目壁纸 `assets/wallpaper/ocean-girl.png`（本地资源，离线也可见）。想换成别的：
- 填网络图片直链到 `theme.background`；或
- 把图片放进 `assets/wallpaper/` 目录，填 `"assets/wallpaper/你的图.jpg"`。

### 字段速查表

| 字段 | 作用 | 必填 |
| --- | --- | --- |
| `id` | 唯一标识 | ✅ |
| `name` | 网站名称 | ✅ |
| `desc` | 网站说明 | ✅ |
| `url` | 网址（新标签页打开） | ✅ |
| `icon` | 图标 emoji 或图片地址 | 推荐 |
| `image` | 卡片封面截图地址（本地 `assets/screenshots/`，铺满封面；留空则用 `icon` emoji） | 否 |
| `category` | 对应分类 id | ✅ |
| `tags` | 标签数组 | 否 |
| `badge` | 右上角角标 | 否 |

## 三、设置管理员

本项目没有传统的「登录后台」，管理员就是**能修改 `data/sites.js` 的人**，有两种方式：

1. **GitHub 协作者（推荐 / 默认）**
   在 GitHub 仓库 **Settings → Collaborators** 添加你信任的人为 Write 权限。
   他就能通过网页编辑 `data/sites.js` 来增删网站、改说明，提交后 Cloudflare 自动重新部署。
   主页右下角齿轮 →「管理网站」默认指向该文件的 GitHub 编辑页（把 `meta.adminUrl` 改成你的仓库地址）。

2. **网页后台令牌（可选 KV 方案）**
   见下一节。只有输入正确 `ADMIN_TOKEN` 的人才能在网页表单里改数据。

> 如果你就是唯一的管理员，什么都不用配置，直接改文件即可。

## 四、可选：网页后台（KV / D1）

默认静态方案已经满足「改一个文件就能管理」。如果你希望**不碰 GitHub、直接在网页表单里增删网站**，
可以用可选的 KV 后台：**它会让主页改为从 KV 读取，每次访问消耗少量免费额度**。

完整步骤见 [`advanced/README.md`](advanced/README.md)，简要流程：

1. Cloudflare 创建 KV 命名空间，在 Pages 项目绑定为 `SITES_KV`
2. 添加机密 `ADMIN_TOKEN`（管理员口令）
3. 把 `advanced/functions/api/sites.js` 复制到根目录 `functions/api/sites.js`
4. 把 `advanced/admin.html` 复制到根目录
5. 在 `data/sites.js` 顶层加一行 `"mode": "api"` 并重新部署
6. 打开 `https://你的域名/admin.html` 输入令牌即可管理

文档里也说明了如何改用 D1 数据库。

## 五、本地预览

不需要安装依赖。用任意静态服务器打开即可（浏览器直接双击 `index.html` 也能看，但建议用服务器）：

```bash
# Python
python -m http.server 8080

# 或 Node
npx serve .
```

然后访问 `http://localhost:8080`。

> 若你在本地部署了可选的 KV 函数，可用 `npx wrangler pages dev .` 预览函数（进阶，默认不需要）。

## 六、常见问题

**Q：部署后页面空白？**
A：检查 Cloudflare Pages 的「构建输出目录」是否填 `/`（根目录）。默认静态方案不需要构建命令。

**Q：改了数据没生效？**
A：确认 GitHub commit 成功，并在 Cloudflare Pages 的部署记录里看到新的成功的部署；浏览器强刷（Ctrl+F5）一次。

**Q：卡片点击后去哪里打开？**
A：所有网站都是**新标签页**打开，不会离开展厅页面。页脚的「YJH」也是新标签页打开 `https://yjhup.com`。

**Q：搜索框怎么用？**
A：左边下拉选引擎（默认百度）。输入文字时**实时筛选本站网站**；按回车或点右侧放大镜则**用所选引擎在新标签页搜索全网**。引擎选择和搜索都是浏览器端行为，不消耗 Cloudflare 额度。

**Q：左侧面板收起后怎么恢复？**
A：收起后原位置会出现一个「标签 ›」按钮，点它即可恢复，不需要刷新页面。

**Q：会不会用光 Cloudflare 免费额度？**
A：默认不会。访客只访问静态文件，静态请求不限量，也不触发函数。只有启用 KV/D1 模式才会消耗函数调用额度。

**Q：数据来源是 JSON 吗？**
A：是。`data/sites.js` 里 `window.SITE_DATA =` 后面就是一个标准 JSON 对象，只是存成 `.js` 以便浏览器直接读取、避免额外网络请求和跨域问题。
